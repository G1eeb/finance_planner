# Finance Planner — Сервис финансового планирования

## Назначение

Приложение предназначено для учёта личных доходов и расходов, контроля месячного бюджета и отслеживания прогресса по финансовым целям. Сервис помогает пользователю понимать, куда уходят деньги, и планировать крупные траты без превышения бюджета.

## Целевая аудитория

- Люди, которые хотят контролировать личные финансы.
- Семьи, ведущие совместный бюджет.
- Пользователи, копящие на крупные покупки (техника, отпуск, автомобиль).
- Студенты и молодые специалисты, начинающие планировать бюджет.

## Предметная область

Личные финансы: учёт доходов и расходов, категоризация операций, планирование месячного бюджета, постановка и отслеживание финансовых целей.

## Основные сущности

- Пользователь
- Финансовая операция (доход / расход)
- Категория операции
- Бюджет на период
- Финансовая цель

## Основные функции

- Добавление доходов и расходов.
- Просмотр текущего баланса.
- Категоризация операций (еда, транспорт, развлечения и т.д.).
- Проверка возможности совершить трату без превышения бюджета.
- Отслеживание прогресса по финансовой цели.

## План развития

На следующих этапах планируется:

- разработка веб-приложения на Django;
- подключение базы данных (PostgreSQL);
- реализация пользователей и аутентификации;
- разработка REST API для работы с операциями и целями;
- контейнеризация приложения (Docker);
- настройка CI/CD.
