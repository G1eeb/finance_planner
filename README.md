# Finance Planner — Сервис финансового планирования

## Назначение

Приложение предназначено для учёта личных доходов и расходов, контроля месячного бюджета и отслеживания прогресса по финансовым целям. Сервис помогает пользователю понимать, куда уходят деньги, и планировать крупные траты без превышения бюджета.

## Целевая аудитория

- Люди, которые хотят контролировать личные финансы.
- Семьи, ведущие совместный бюджет.
- Пользователи, копящие на крупные покупки (техника, отпуск, автомобиль).
- Студенты и молодые специалисты, начинающие планировать бюджет.

## Предметная область

Личные финансы: учёт доходов и расходов, категоризация операций, планирование месячного бюджета, постановка и отслеживание финансовых целей.

## Основные функции

- Расчет бюджета
- Проверка бюджета
- Отчет
